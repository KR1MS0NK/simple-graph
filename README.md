# simple-graph
an app for drawing graphs, calculating gradient and drawing a line of best fit
- graph sheet workspace that allows you to zoom in and out 
- when the user clicks on the add point button, a popup should open where the user enter the x any y values with a plot button
- plotting the point shows it as a dot on the workspace
- gradient button shows the gradient of the plotted points
- line/ curve button draws a line of best fit or a curve on the workspace
- there should be an option to plot only values on the y axis with the x axis having fix interval values
